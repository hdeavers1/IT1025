### Information System Components
The components of Information System are hardware, software, data, people, and processes. The first three are technology. Hardware is the physical portions: the computers, keyboards, disk drives, etc. Software is the set of instructions that tell the hardware what to do, it is not tangible. Data is the collection of information. The next component is People, and people are really important because they are the ones that have the ideas and knowledge to use these prior components. The final part is Process, where all the parts come together to achieve a goal.

#### Application, Utility, and Operating Systems
The role of Application software is to perform specific tasks such as video games or word processors. Utility Software are programs that allow you to modify or fix you computer in some way. An example of a Utility software is an anti-malware software. The roles of Operating Systems is to manage hardware resources of the computer, provide user-interface components, and provide a platform for software developers to write applications. An example of an Operating System would be Microsoft Windows.
#### ERP
ERP, or Enterprise Resource Planning, is made with the purpose to keep an organization within one program. The software uses a central database that is implemented throughout the entire organization. An example of this would Oracle or Microsoft.
#### Virtualization
Virtualization is technology that lets the user create IT services using resources that are traditionally bound to hardware. It allows the user to use a physical machine's full capacity by distributing its capabilities among many users or environments. A common issue that is solved using Virtualization is creating multiple servers under one hardware. A Hypervisor is basically an emulator (it emulates a virtual machine to perform tasks). The role of Hypervisors in Virtualization is that it can take physical resources and divide them into virual environments for use.

### Computer Architecture
#### CPU
A. The CPU, or Central Processing Unit, retrieves and executes instructions. The ALU is a component within the CPU. The ALU, Arithmetic Logic Unit, does all of the mathematical operations for the CPU. The CPU will retrieve a set of instructions from the RAM and if there is a mathematical operation, it will be sent to the ALU to conduct the operation. The ALU will output the result to the Register, which is just a temporary holding place for the result. The result will go on to the CPU "bus", which is a bunch of wire and is used to transport the value to where ever is needed, then the Register will be cleared for another result. 
B. Consider the situation where you are using the self check-out at a grocery store. 
The input in this case would be scanning a barcode, it is then checked by the CPU. The CPU looks for a match of information, once it is found, the object's information (name and price) would be output as a display on the monitor.
CPU: Does all of the calculations while referencing the memory.
Input: Takes input from things such as the mouse, camera, keyboard, and camera. The input is then stored as binary inside the computer.
Output: Outputs information like displaying on a monitor or smartphone. The output is from the input and CPU.
#### Gates and Circuits
Truth table: A truth table is a table that displays all of the possible inputs and outputs that can happen at a gate. 
AND gate compared to OR gate: An AND gate works on the condition that both electrical inputs are on, then a number 1 is output, otherwise (if one or none are on) a zero will be output. An OR gate works differently, a 1 will be output if one or both are on. A zero will only be output if both are not on.
