### Information System Components
The components of Information System are hardware, software, data, people, and processes. The first three are technology. Hardware is the physical portions: the computers, keyboards, disk drives, etc. Software is the set of instructions that tell the hardware what to do, it is not tangible. Data is the collection of information. The next component is People, and people are really important because they are the ones that have the ideas and knowledge to use these prior components. The final part is Process, where all the parts come together to achieve a goal.

#### Application, Utility, and Operating Systems
The role of Application software is to performs specific tasks such as video games or word processors. Utility Software are programs that allow you to modify or fix you computer in some way. An example of a Utility software is an anti-malware software. The roles of Operating Systems is to manage hardware resources of the computer, provide user-interface components, and provide a platform for software developers to write applications. An example of an Operating System would be Microsoft Windows.
#### ERP
ERP, or Enterprise Resource Planning, is made with the purpose to keep an organization within one program. The softwar uses a central database that is implemented throughout the entire organization. An example of this would Oracle or Microsoft.
#### Virtualization
Virtualizat ion is technology that lets the user create IT services using resources that are traditionally bound to hardware. It allows the user to use a physical machine's full capacity by distributing its capabilities among many users or environments. A common issue that is solved using Virtualization is creating multiple servers under one hardware. A Hypervisor is basically an emulator (it emulates a virtual machine to perform tasks). The role of Hypervisors in Virtualization is that it can take physical resources and divide them into virual environments for use.
