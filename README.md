Image Format (Lossless vs. Lossy Compression):
Lossless: File compression that reduces a file's size with no loss of quality. The resulting files are typically much larger than image and audio files compressed with lossy compression.
Lossy: File compression that results in lost data and quality from the original version. The resulting file often takes up much less disk space than the original.
Similarities and Differences between .jpg, .gif, and .png:
GIF: Graphics Interchange Format, supports up to 8 bits per pixel, allows for animated images.
JPEG: Joint Photographic Expers Group, an image format that uses lossy compression to create smaller file sizes, allows the designer to tune the amount of compression used, prone to artifacting.
PNG: Portable Network Graphics uses lossless data compression, created to replace GIF format, supports a number of transparency options, supports palette-based color, greyscale, RGBA, and RGB color spaces.

### Computer Architecture
#### CPU
A. The CPU, or Central Processing Unit, retrieves and executes instructions. The ALU is a component within the CPU. The ALU, Arithmetic Logic Unit, does all of the mathematical operations for the CPU. The CPU will retrieve a set of instructions from the RAM and if there is a mathematical operation, it will be sent to the ALU to conduct the operation. The ALU will output the result to the Register, which is just a temporary holding place for the result. The result will go on to the CPU "bus", which is a bunch of wire and is used to transport the value to where ever is needed, then the Register will be cleared for another result. 
B. Consider the situation where you are using the self check-out at a grocery store. 
The input in this case would be scanning a barcode, it is then checked by the CPU. The CPU looks for a match of information, once it is found, the object's information (name and price) would be output as a display on the monitor.
CPU: Does all of the calculations while referencing the memory.
Input: Takes input from things such as the mouse, camera, keyboard, and camera. The input is then stored as binary inside the computer.
Output: Outputs information like displaying on a monitor or smartphone. The output is from the input and CPU.
#### Gates and Circuits
Truth table: A truth table is a table that displays all of the possible inputs and outputs that can happen at a gate. 
AND gate compared to OR gate: An AND gate works on the condition that both electrical inputs are on, then a number 1 is output, otherwise (if one or none are on) a zero will be output. An OR gate works differently, a 1 will be output if one or both are on. A zero will only be output if both are not on.

#### Storage
Hard Drive Latency: Latency is the average time for the sector being accessed to rotate into position under a head, after a completed seek. A drive's average access time is the interval between the time a request for data is made by the system and the time the data is available from the drive. 
Hard Drive Transfer Rates: The disk transfer rate is the speed at which data is transferred to and from the disk media and is a function of the recording frequency. Generally described in megabytes per second (MBps).
Solid State hard drive: a storage device that uses solid state memory to store data. SSDs have no moving parts compared to traditional hard drives. Data is stored into word length pieces and stored in memory, which is then accessed instantaneously using system-wide addresses.

### Networking
#### Data Transmission
Data Transmission- The process of sending digital or analog data over a communication medium to one or more computing, network, communication or electronic devices.
Packet- The fundamental unit of data transmitted over the Internet.
Packet-Switching- When a message's packets are sent on the Internet, routers try to find the optimal route for each packet. This can result in packets being sent on different routes to their destination. After the packets arrive they are re-assembled into the original message for the recipient.
IP Address- A unique identifying number for evert device on the Internet.
DNS- Stands for "domain name server or system." DNS acts as the directory of websites on the Internet.
Protocol- The set of rules that govern how communications take place on a network.

#### Protocols
There are thousands of different network protocols, but they all perform one of three primary action: Communcation, Network management, and Security.
Communication: Automation is an example of Communication Protocol, these protocols are used to automate different processes in both commercial and personal settings.
Network management: Connection is an example of Network Management protocol, these protocols establish and maintain stable connections between different devices on the same network.
Security: Encryption is an example of Security protocol, encryption protocols protect data and secure areas by requiring users to input a secret key or password in order to access that information.
HTTP: hypertext transfer protocol. The protocol used for viewing webpages on the Internet. 
Protocols used by secure HTTP to protect data: HTTPS encrypts the data that is being retrieved by HTTP and uses encryption algorithms to scramble the data that is being transfered.
SSL: Secure Sockets layer, protocal that uses public key encryption to secure data. Websites will send a SSL certificate to prove its trustworthyness. 
TLS: Transport layer security, successor to SSL. Authenticates the server, client and encrypts the data.
